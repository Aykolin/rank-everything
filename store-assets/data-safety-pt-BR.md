# Declaração de segurança de dados

Respostas preparadas para a seção “Segurança dos dados” da Google Play, considerando a versão 0.5.0.

- O app coleta ou compartilha algum dado obrigatório do usuário? **Não**.
- O app compartilha dados com terceiros? **Não**.
- O app possui anúncios? **Não**.
- O app exige conta? **Não**.
- O app permite solicitar exclusão de conta? **Não se aplica, pois não existem contas**.
- O usuário pode excluir os dados? **Sim**, dentro do app, limpando os dados do aplicativo ou desinstalando-o.
- Os dados são processados fora do aparelho? **Não**.
- Público-alvo sugerido: **público geral**, sem conteúdo direcionado especificamente a crianças.

Revise esta declaração se forem adicionados sincronização, login, analytics, publicidade, backup remoto, compartilhamento ou qualquer SDK que transmita informações.
